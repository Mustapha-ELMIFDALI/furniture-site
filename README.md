# Furniture – Modern Furniture Store

Responsive furniture e-commerce landing page built with HTML, Tailwind CSS (CDN) and vanilla JavaScript, with dark mode.

- `index.html` + `style.css` + `script.js` – the site split into files
- `furniture.html` – the same site in a single file

Open `index.html` in a browser (internet needed for Tailwind, fonts and Unsplash photos).
